# Dragon Browser 🐉

متصفح خاص، مبني على Electron (محرك Chromium)، بحجب إعلانات/تتبع مدمج (built-in، بلا إضافات).

## الستاك (100% مجاني، بلا حاجة لبيسي قوي)
- **GitHub** — استضافة الكود (مجاني، repo عمومي)
- **GitHub Actions** — البناء التلقائي لـ Windows + macOS + Linux (مجاني للـ repos العمومية)
- **Electron + electron-builder** — تغليف المتصفح كتطبيق قابل للتنصيب
- **@cliqz/adblocker-electron** — حجب الإعلانات والتتبع (مفتوحة المصدر، نفس الفكرة المستخدمة في Brave)

## كيفاش تبني نسخة قابلة للتنصيب (بلا بيسي تاعك):

1. أنشئ حساب GitHub مجاني (إذا ما عندكش)
2. أنشئ repository جديد اسمو `dragon-browser` (خليه Public باش GitHub Actions يكون مجاني بلا حدود)
3. ارفع هذا المجلد كامل للـ repo:
   ```
   git init
   git add .
   git commit -m "Dragon Browser - initial scaffold"
   git branch -M main
   git remote add origin https://github.com/USERNAME/dragon-browser.git
   git push -u origin main
   ```
4. GitHub Actions راح يبدا يخدم أوتوماتيكيا (تلقاه في تبويب "Actions" في الـ repo)
5. بعد ما يخلص البناء (يدوم بين 5-15 دقيقة)، تلقى الملفات القابلة للتنصيب (.exe / .dmg / .AppImage) في تبويب "Actions" > اختر آخر build > "Artifacts"

## تحسينات الأداء المضافة (RAM/CPU) — المرحلة 2
- **إيقاف تلقائي للتبويبات غير النشيطة (Tab Suspension):** أي تبويب ما تلمسوش لمدة 5 دقايق، يتسكر بروسيس الرندرة تاعو كليا ويتحرر الرام الحقيقية، ونحتفظو فقط بالعنوان والرابط — كي ترجع لهذا التبويب، يتعاود تحميله تلقائيا. هذا أكبر توفير للـ RAM لأن التبويبات المفتوحة بصح المنسية هي أكبر مستهلك للذاكرة في أي متصفح
- **backgroundThrottling:** التبويبات المفتوحة بصح غير الظاهرة، الـ JS timers تاعها تتبطأ تلقائيا (يقلل استهلاك CPU)
- **sandbox لكل تبويب:** عزل كامل + يمنع تسرب الذاكرة بين التبويبات
- **تعطيل ميزات غير مستخدمة:** spellcheck المدمج، WebSQL القديمة
- **حد أقصى لذاكرة V8:** `--max-old-space-size=256` لكل عملية رندرة، يمنع أي صفحة وحدة من "تاكل" رام بلا حدود
- **حد لعدد عمليات الرندرة المتوازية:** `renderer-process-limit=4`

⚠️ **صراحة:** هذي تحسينات حقيقية وتأثيرها ملموس (خصوصا Tab Suspension)، بصح تبقى Electron بطبيعتها أثقل من فورك Chromium مباشر، لأن كل نافذة Electron تحمل معاها Node.js runtime إضافي فوق محرك Chromium. رقم "400-450MB مع 10 تبويبات" يبقى **هدف بعيد المدى** يتحقق أكثر مع فورك Chromium حقيقي. مع Electron + هذي التحسينات، التوقع الواقعي أقرب لـ 250-350MB مع تبويب أو تبويبين نشيطين + الباقي موقوف (suspended)، وهذا رقم لسا نتحقق منه بالاختبار الفعلي بعد البناء.

## ملاحظة صادقة
هذا النموذج مبني بـ Electron، ماشي فورك Chromium حقيقي. استهلاك الرام راح يكون أعلى من الهدف النهائي (~400-450MB) في هذي المرحلة، ونحسنوه تدريجيا. فورك Chromium حقيقي (نفس Brave/Vivaldi) يحتاج بنية بناء ثقيلة (سيرفر قوي/بيسي مخصص) — خطوة مستقبلية إذا المشروع نجح وحبيت تستثمر فيها.
